# Student-Management-System
🎓 Student Management System | Java + JDBC + MySQL | Add, View, Search, Update &amp; Delete students
A console-based Student Management System built with Java and MySQL.

## Tech Stack
- Java
- MySQL
- JDBC

## Features
- Add Student
- View All Students
- Search by ID / Name
- Update Student
- Delete Student
- Total Count & Average Marks

## Project Structure
- DBConnection.java → Database connection
- Student.java      → Student model
- StudentDAO.java   → CRUD operations
- Main.java         → Menu & user input

## How to Run
1. Create MySQL database using student_db
2. Update password in DBConnection.java
3. Add MySQL JDBC connector jar
4. Run Main.java
